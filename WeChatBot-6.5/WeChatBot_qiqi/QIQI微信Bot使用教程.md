# QIQI 微信 Bot 6.9 安装与使用教程

适用版本：QIQI 微信 Bot 6.9  
用途：在 Windows 电脑上运行微信 Bot，完成中文情感聊天、角色扮演、图片识别、联网搜索、主动消息和记忆管理。

> 下载说明：微信安装包、Python 安装包和 Bot 项目包均可在 QQ 交流群 `QQ_GROUP_ID_REMOVED` 获取。群主 QQ：`GROUP_OWNER_ID_REMOVED`。

## 1. 使用前必读

- 系统：Windows 10 或 Windows 11，64 位。
- 微信电脑版：推荐并按 `4.1.2` 版本使用。其他版本不保证能够被 Bot 正常控制。
- Python：支持 64 位 Python `3.9–3.12`，推荐 Python `3.11`。
- 安装 Python 时必须勾选 `Add Python to PATH`。
- 使用 QIQI API 前，需要准备可用的 QIQI 账号、账户余额和 API Key。
- 不要把 API Key 发给他人，也不要在截图中显示完整 Key。

> 版本提醒：旧教程中“只支持微信 3.9、不支持微信 4.x”的说明已经过时。当前项目启动脚本已适配微信 4.1.2，并为 Python 3.9、3.10、3.11、3.12 分别提供 64 位控制库。

## 2. 下载并安装环境

### 2.1 下载文件

加入 QQ 交流群 `QQ_GROUP_ID_REMOVED`，下载以下内容：

1. 微信电脑版 4.1.2 安装包。
2. Python 3.11 64 位安装包。
3. QIQI 微信 Bot 6.9 项目压缩包。

### 2.2 安装 Python

1. 运行 Python 3.11 安装程序。
2. 在安装窗口底部勾选 `Add Python to PATH`。
3. 选择立即安装，等待完成。
4. 按 `Win + R`，输入 `cmd` 并回车。
5. 输入 `python --version`。如果显示 `Python 3.11.x`，说明安装成功。

### 2.3 安装并登录微信

1. 安装微信电脑版 4.1.2。
2. 正常登录微信，并保持微信在后台运行。
3. 第一次测试时建议让微信主窗口保持打开。
4. 如果需要接收语音消息，请在微信“设置 → 通用设置”中开启“聊天中的语音消息自动转文字”。

## 3. QIQI API 与令牌分组

QIQI API 地址：`https://ai.qiqiapi.top/`

> 服务范围提醒：使用前请阅读并遵守 QIQI 页面中的用户协议、授权范围及所在地法律法规；是否可用以平台当时显示的协议和账户权限为准。

登录后进入“控制台 → 令牌管理”，点击“添加令牌”。建议按用途命名，例如：

- `wxbot-gpt`
- `wxbot-claude`
- `wxbot-grok`
- `wxbot-deepseek`

### 3.1 最重要的分组规则

> **一个令牌属于哪个分组，就只能调用该分组允许的模型。QIQI 的 Key 并不是默认拥有全部模型。**

因此，选择模型之前必须先选择正确的令牌分组。分组不匹配时，可能出现：

- Bot 中只能选择一个或少量模型；
- 目标模型不出现在模型下拉框；
- 提示“当前模型不在此 Key 可用列表”；
- 返回“模型不存在”“无权访问”“上游请求失败”等错误。

以下分组与模型核对于 2026 年 7 月 19 日。QIQI 会调整模型，最终以 QIQI“模型广场”和令牌页面实时显示为准。

| 令牌分组 | 主要可用模型 | 推荐用途 |
|---|---|---|
| `gpt-活动` | GPT-5.4 Mini、GPT-5.4、GPT-5.5、GPT-5.6 Luna、Sol、Terra | 主聊天、辅助、识图 |
| `claude-kiro` | Claude Sonnet 5、Sonnet 4.6、Opus 4.6/4.7/4.8、Fable 5 | 高质量情感聊天、角色扮演 |
| `deepseek` | DeepSeek V4 Flash、DeepSeek V4 Pro | 中文聊天、低成本聊天 |
| `grok纯福利` | Grok 4.5 | 联网搜索或低成本试用 |
| `硅基` | Qwen/Qwen3.6-35B-A3B | 国产模型备选 |
| `image` | 图片生成模型 | 图片生成，不是 Bot 的图片识别模型 |
| `系统测试-勿选` | 测试模型 | 普通用户不要选择 |

### 3.2 创建令牌的建议

1. 进入“令牌管理”。
2. 点击“添加令牌”。
3. 填写容易识别的名称。
4. 根据需要选择分组。
5. 创建后复制 Key，并保存在安全的位置。
6. 不要点击眼睛后截取包含完整 Key 的图片。

### 3.3 一个 Key 还是多个 Key

如果主聊天、辅助、识图和联网全部使用 `gpt-活动` 分组内模型，可以先使用同一个 `gpt-活动` Key。

如果功能跨分组，则需要分别创建 Key。例如：

- 主聊天使用 Claude：填写 `claude-kiro` Key；
- 辅助和图片识别使用 GPT：填写 `gpt-活动` Key；
- 联网搜索使用 Grok：填写 `grok纯福利` Key。

> “快速上手”页面会把同一个 Key 同时填入主聊天、辅助、图片识别和联网配置。跨分组配置时，不要只停留在快速上手页面，必须进入完整配置页面，为各功能分别填写正确的 Key。

### 3.4 成人话题模型必须使用独立凭据

开启“使用独立成人话题模型”后，必须在“成人模式配置”中单独填写：

- 成人模型 API Base URL；
- 成人模型专用 API Key；
- 成人话题模型名称。

主 Chat 的 API 地址和 Key 不会自动复用。即使成人模型与主 Chat 都使用 QIQI API，也需要在成人模式配置中再次填写对应分组的 Key。使用 Grok 4.5 时，令牌分组必须实际包含该模型；能否处理某类内容仍以 API 服务商当时的模型能力、账户权限和使用规则为准。

不要添加“破甲”、越狱或绕过服务商安全限制的提示文件。这类内容不保证有效，容易造成回复不稳定、答非所问、账号风控或上游拒绝。

## 4. 模型选择建议

这个 Bot 的主要任务是中文情感聊天，因此应优先考虑中文口语、情绪承接、角色一致性、回复速度和成本，而不是只看推理能力。

### 4.1 主聊天模型

| 目标 | 推荐模型 | 所需分组 | 说明 |
|---|---|---|---|
| 默认综合推荐 | `gpt-5.6-terra` | `gpt-活动` | 质量、速度与成本较均衡 |
| 情感效果优先 | `claude-sonnet-5` | `claude-kiro` | 情绪细腻、人物口吻和角色聊天值得优先测试 |
| 更高效果 | `gpt-5.6-sol` | `gpt-活动` | 效果优先，成本相对更高 |
| 性价比 | `gpt-5.6-luna` | `gpt-活动` | 适合高频聊天 |
| 中文低成本 | `deepseek-v4-flash` | `deepseek` | 成本较低，复杂情绪轮次可能不如高质量模型 |

### 4.2 辅助模型

辅助模型用于联网判断、提醒解析、表情判断和记忆总结，不需要使用最贵模型。

- 推荐：`gpt-5.4-mini`，分组 `gpt-活动`。
- 低成本：`deepseek-v4-flash`，分组 `deepseek`。
- 启用辅助模型后，主模型可以更专注于聊天回复。

### 4.3 图片识别模型

- 效果推荐：`gpt-5.4`，分组 `gpt-活动`。
- 性价比推荐：`gpt-5.4-mini`，分组 `gpt-活动`。
- `image` 分组中的图片生成模型不能直接代替图片识别模型。

### 4.4 联网搜索模型

- 推荐：`grok-4.5`，分组 `grok纯福利`。
- 该分组属于福利性质，模型、倍率或稳定性可能变化，建议只用于联网或备用，不建议作为长期情感主模型。
- 不需要最新信息时可以关闭联网搜索，以降低延迟和消耗。

### 4.5 三套直接可用的配置

**简单稳定方案**

- 一个 `gpt-活动` Key；
- 主聊天：GPT-5.6 Terra；
- 辅助：GPT-5.4 Mini；
- 图片识别：GPT-5.4 Mini；
- 联网搜索：关闭。

**情感效果优先方案**

- 主聊天：Claude Sonnet 5，使用 `claude-kiro` Key；
- 辅助：GPT-5.4 Mini，使用 `gpt-活动` Key；
- 图片识别：GPT-5.4，使用 `gpt-活动` Key；
- 联网搜索：Grok 4.5，使用 `grok纯福利` Key。

**性价比方案**

- 主聊天：GPT-5.6 Luna，使用 `gpt-活动` Key；
- 辅助：GPT-5.4 Mini，使用 `gpt-活动` Key；
- 图片识别：按需开启；
- 联网搜索：按需开启。

## 5. 第一次启动 Bot

1. 解压项目压缩包。不要直接在压缩包内运行。
2. 项目路径尽量简短，不要放在需要管理员权限的系统目录。
3. 双击项目目录中的 `Run.bat`。
4. 首次运行会检查微信、Python、pip，并自动安装依赖。
5. 安装期间不要关闭黑色命令窗口。
6. 启动成功后会自动打开配置页面。默认地址通常是 `http://127.0.0.1:5000/`。

如果页面没有自动打开，请查看命令窗口显示的“访问地址”，复制到浏览器中打开。

## 6. 快速上手配置

1. API 服务商选择 `QIQI API`。
2. 填入 QIQI API Key。
3. 选择主聊天模型。
4. 添加需要监听的微信好友昵称或群聊名称。
5. 为该用户选择角色 Prompt。
6. 保存后进入完整配置页面。

> 如果模型列表只有一个或没有目标模型，先检查令牌分组，不要反复重装 Bot。令牌分组才是决定可用模型的关键。

## 7. 完整配置页面

### 7.1 用户列表

- 填写微信中显示的准确昵称或群聊名称。
- 大小写、空格和特殊符号应与微信保持一致。
- 每个用户可以分配不同的角色 Prompt。

### 7.2 Prompt 管理

- 可以使用自带角色文件，也可以创建新角色。
- Prompt 中应明确人物身份、语气、关系、故事背景和不允许发生的行为。
- 情感聊天建议避免互相冲突的设定，否则模型容易前言不答后语。

### 7.3 Chat 模型配置

1. API 服务商选择 QIQI API。
2. 选择令牌分组允许的模型。
3. 填入对应分组的 Key。
4. 回复最大 Token 默认可先保持 2000。
5. 温度建议保持 0.7 左右，以兼顾自然表达和人物稳定性。

### 7.4 辅助、识图和联网

- 使用同一分组时可以填写同一个 Key。
- 使用不同分组时必须填写各自的 Key。
- 点击模型旁的刷新按钮，可以根据当前保存的 QIQI Key 更新模型列表。
- Key 无权使用的模型不会作为可选模型显示。

### 7.5 保存并启动

1. 点击顶部“保存配置”。
2. 保存成功后点击 `Start Bot`。
3. 首次启动时保持微信窗口打开。
4. 用已加入用户列表的微信账号发送一条普通文字进行测试。

## 8. 常见问题

### 8.1 模型只有一个，或找不到想要的模型

原因通常不是 Bot 损坏，而是 QIQI 令牌分组不匹配。

解决方法：

1. 登录 QIQI API。
2. 进入“控制台 → 令牌管理”。
3. 查看 Key 的“分组”和“可用模型”。
4. 创建正确分组的新 Key。
5. 回到 Bot，填入新 Key，保存并刷新模型列表。

### 8.2 报“模型不存在、无权限或上游请求失败”

- 检查模型是否属于当前 Key 的分组；
- 检查账户余额；
- 检查 Key 是否复制完整；
- 检查 QIQI 使用日志；
- 福利模型可能临时调整，可更换为稳定模型重试。

### 8.3 点击 Start Bot 后找不到微信窗口

- 确认微信 4.1.2 已安装并登录；
- 完全退出微信后重新打开；
- 保持微信主界面打开，再启动 Bot；
- 不要同时运行多个微信控制程序。

### 8.4 `Run.bat` 提示找不到 Python

- 重新安装 Python 3.11 64 位；
- 安装时勾选 `Add Python to PATH`；
- 重新打开 `Run.bat`。

### 8.5 页面打不开

- 不要关闭运行 `Run.bat` 的命令窗口；
- 查看窗口中的实际访问地址；
- 尝试访问 `http://127.0.0.1:5000/`；
- 如果修改过端口，以 `config.py` 中的 `PORT` 为准。

### 8.6 回复答非所问或人物跑偏

- 优先换用 GPT-5.6 Terra 或 Claude Sonnet 5；
- 检查 Prompt 是否包含冲突设定；
- 不要把低成本辅助模型当作高质量情感主模型；
- 清理错误的短期上下文后重新测试；
- 一次只测试一个变量，避免同时更换模型、Prompt 和记忆配置。

## 9. 数据迁移与安全

换电脑或重装时，建议保留：

- `config.py`
- `prompts` 文件夹
- `CoreMemory` 文件夹
- `Memory_Temp` 文件夹（如果存在）
- 用户信息、好感度、聊天上下文和主动话题相关 JSON 文件
- `emojis` 文件夹
- `forum_data` 文件夹

使用程序内的完整数据导出与导入功能通常更安全。迁移后应重新检查 API Key、微信昵称和文件路径。
